# qtpatuti · q_plat

Single-file quant research frontend, cloud-only market ingestion, immutable MongoDB Atlas snapshots and private workspaces. [Production](https://q-plat.vercel.app) · [Download the same index.html](https://q-plat.vercel.app/download).

Write an edge or select an editable example, choose six distinct datasets, then **Run on 6 datasets**. One durable job executes panels sequentially; its six live screens show each dataset's progress, price and edge score. Each verified panel remains a normal, independently readable run. A private guest workspace starts automatically (24-hour access, three run attempts). Choose **Save workspace** and set a name/passphrase to preserve access to its research. Returning users open Workspace and sign in. Runs reopens reports, retries jobs and compares experiments. Ctrl/Cmd K opens navigation; Ctrl/Cmd Enter starts the six-dataset job.

**AI** creates scoped, revocable 30-day tokens for the [MCP/API integration](docs/ai.md). [OpenAPI](https://q-plat.vercel.app/openapi.json) and `/mcp` use the same workspace authorization and research engine. No paid AI provider is required. The repository remains public and named `q_plat`; the product is now **qtpatuti**, using the same production alias, Atlas snapshots and saved workspaces.

The [interaction review](docs/interaction-review.md) records the seven official references, evidence limitations, design decisions and state-by-state verification targets. Authenticated reference applications were not falsely claimed as tested.

**Equities:** ten [historical sector research panels](docs/equity-datasets.md), each with six selected US stocks and daily adjusted OHLCV for 2012–2017. Choose **US equities / …** in the dataset selector. Bounded API/MCP windows and run source traces expose original prices, dividends and splits; Sources shows quarantine reasons, calendar gaps and hashes. All ten use one frozen public-domain WIKI archive; they are not ETF data, independent vendor feeds, current quotes or survivorship-free universes. Read the source's discontinued-service/data-quality warning before interpreting results.

**Jobs:** the editor and Runs show stage, completion percentage and elapsed time. Tracking resumes after reload; Cancel releases the editor, and Retry creates a fresh job. Percentages represent weighted pipeline stages and confirmed saved batches, not a time estimate. A run reaches 100% only after cloud readback verification and publication. [Pipeline measurements and verification](docs/job-performance.md).

Ingestion refuses to execute outside a Vercel deployment. `npm run test:e2e` runs the actual production UI in disposable Chromium contexts; install Chromium with `npx playwright install chromium` first. It prints only assertion names/counts/hashes, with no HAR, trace, screenshots or market payload artifacts.

`node scripts/equities-e2e.mjs` checks all ten ready equity snapshots, a split audit, full-history custom-edge runs, reproducibility, robustness, MCP access and the web/mobile result journey. It creates real private test runs on Atlas and prints scalar evidence only. Owner command `node scripts/admin.mjs import wiki_sectors` imports the bundle in cloud or verifies existing ready counts; it does not download datasets to the invoking machine.

Production environment: `MONGODB_URI`, `MONGODB_DB=q_plat`, `OWNER_KEY`, `APP_ORIGIN`. Secrets are server-side only. A database identity must be restricted to `readWrite` on the app database and its named test database. Do not open network access or enable paid features to work around connectivity.

## Architecture

`index.html → same-origin /api → Atlas`. Next.js provides only backend routes and durable Vercel Workflow handlers; it does not build or rewrite the frontend. `/` and `/download` return identical source bytes. A downloaded `file://` document can read bounded public catalog/window endpoints using anonymous CORS; private operations require production HTTPS and an HTTP-only session cookie.

`lib/dsl.mjs` is a bounded parser/interpreter (no eval). `lib/engine.mjs` and `lib/metrics.mjs` are pure calculation modules. `lib/ingest.mjs` fetches allowlisted publishers into bounded cloud RAM, checks normalized hashes and readback, then publishes an immutable ready snapshot. Labels never enter the DSL feature allowlist. `lib/jobs.mjs` persists outputs in bounded documents and idempotent bulk writes; Workflow persists job execution across disconnects. Workflow inputs/outputs contain IDs/counts/hashes, not market panels. Atlas is the long-term store.

The free Atlas setup uses separate M0 clusters. `MONGODB_CORE_URI` stores workspaces, jobs, edges and research results; `MONGODB_DATA_URI` stores `bars`, `datasets` and `dataset_versions`. For Vercel Hobby's dynamic egress, `render.yaml` defines an optional Singapore relay. It keeps both Atlas URIs in server-side environment variables, verifies short-lived Ed25519 request signatures with a public key, accepts an allowlist of collection operations, and routes those three market-data collections to the data cluster. The signing private key stays in Vercel; Render receives only the public key. Add only the relay service's published outbound CIDRs to both Atlas projects; never use `0.0.0.0/0`. The relay stops at an estimated 10 GiB of monthly traffic. Render Free sleeps after 15 idle minutes and can take about a minute to wake, so this zero-cost bridge has cold starts and no production uptime guarantee. A later always-on, fixed-egress host would be required for dependable production without those cold starts.

## Research conventions

- UCI is 750 weekly OHLCV observations for 30 assets in 2011 H1, CC BY 4.0, attributed to Michael Brown / UCI DOI 10.24432/C5788V. Price-only, not total return. The benchmark is `equal-weight sample`, not the official Dow Jones index.
- ECB is six daily reference FX rates quoted in foreign currency per EUR, 2010–2024. Source: ECB statistics. Raw statistics are preserved; derived statistics are labeled. No executable OHLC/volume is fabricated.
- Synthetic generator: seed 271828, 28 assets × 1,200 weekday sessions with missing rows, late listing, sectors, regimes and zero volume. The split fixture is separate.
- Average ties, ascending percentile rank. Rolling uses dataset session slots, requires full windows and ddof=1 standard deviation. Missing/zero denominator returns null. Historical publication times are conservative proxies, not point-in-time verified data.
- OHLC evaluation label: `open(t+1+h)/open(t+1)-1`. Per-session Spearman IC with block bootstrap. Ideal long/short is a diagnostic (gross 1/net 0), not a borrow-enabled account. Quantile paths with overlapping horizons are diagnostics.
- Long-only orders are sized at decision close, filled at a later observed open with per-side fees/slippage, lots, cash and participation constraints. Missing open/zero volume never fills. Cash settlement is immediate; last prices mark stale positions; terminal holdings are not liquidated. No dividends or borrow model.
- Chronological splits purge labels crossing the next cutoff. Walk-forward selects top-K from two predeclared candidates on train only and reports every candidate. Opening a report marks holdout as viewed. Research metrics are never required to be profitable.
