                  Fields, operators & missing values
                  

                  

                    + − * /, comparisons, and / or / not. Variables are assigned
                    once, one per line. where(condition, a, b),
                    clip(x, lo, hi), abs.
                  

                  

                    lag(x,n), delta(x,n), returns(x,n), ts_mean(x,n),
                      ts_std(x,n), ts_rank(x,n): n is an integer 1–252, in dataset sessions. Rolling
                    requires the entire window; std uses ddof=1.
                  

                  

                    rank(x), zscore(x), group_rank(x), group_demean(x)
                    use the current cross-section only. Rank is ascending 0–1;
                    average ties. Missing group → N/A. Zero denominator,
                    incomplete windows and nonfinite inputs → N/A. No imports,
                    lookahead or arbitrary Python.
